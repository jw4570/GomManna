## 1. 개인정보 처리 목적

곰만나는 초대받은 사람들과 모임에 참여하고, 사용자가 선택한 동안 위치·메모·사진을 공유하기 위해 정보를 처리합니다. 익명 사용자 구분과 요청 인증, 모임 운영, 부정 접근 방지, 이용자 문의 대응에도 필요한 정보를 처리합니다. 아래 내용은 현재 구현을 설명하며, 보유 기간·운영자·위탁 및 국외이전 정보가 확정되기 전에는 최종 정책으로 사용할 수 없습니다.

## 2. 처리하는 정보와 수집 시점

앱 이용 시: 서버가 발급한 익명 사용자 ID와 인증 토큰, 토큰 만료 시각. 인증 토큰은 기기의 Keychain에 보관합니다. 실명·전화번호·이메일을 입력하는 회원가입 절차는 없습니다.

모임 생성·참여 시: 사용자가 입력한 모임 이름과 닉네임, 모임·멤버 ID, 참여·종료 시각, 초대 코드와 공유 설정.

위치 공유를 켰을 때: 위도·경도, 위치 정확도, 위치 측정·서버 수신 시각, 공유 회차 및 업데이트 순서. iOS의 위치 권한과 모임의 공유 설정을 모두 사용합니다. 정확한 위치를 허용하지 않으면 기기에서 제공하는 대략적 위치를 사용할 수 있습니다.

메모·사진을 직접 등록했을 때: 메모 내용, 작성 시각과 작성 당시 위치, 직접 선택한 사진, 첨부·업로드 시각. 사진은 방향을 보정하고 축소하여 전송하며 서버는 이미지를 다시 인코딩해 메타데이터를 제거합니다. 사진에 보이는 얼굴·문자·장소까지 자동으로 가려지는 것은 아닙니다.

기기 안에만 저장하는 정보: 현재 모임 복원을 위한 모임·사용자 ID, 동물 프로필 선택, 화면 모드. 지도 마킹은 현재 기기의 화면 상태로만 유지합니다.

접속 과정에서 서버 및 인프라의 보안·운영 로그에 IP 주소, 접속 시각과 요청 정보가 기록될 수 있습니다. 실제 로그 수집 범위와 보관 기간은 운영 설정을 확인해 확정합니다. 문의 이메일을 보내면 사용자가 작성한 연락처와 문의 내용을 문의 처리 목적으로 사용합니다.

현재 앱에는 광고 추적 SDK, 광고 식별자 수집, 자체 분석 SDK, 푸시 알림 전송 기능을 포함하지 않습니다. 지도 표시에는 Apple 지도 서비스를 사용하며 해당 서비스에는 Apple의 정책이 적용됩니다.

## 3. 모임 멤버에게 공유되는 정보

같은 모임의 참가자는 닉네임과 참여 상태를 확인할 수 있습니다. 위치 공유가 켜진 동안에는 현재 공유 회차의 위치와 작성한 메모·첨부 사진을 같은 모임 멤버가 볼 수 있습니다. 공유를 끄면 서버에서 해당 위치·메모·사진을 다른 멤버에게 제공하지 않습니다.

초대 코드와 QR을 받은 사람이 모임에 참여할 수 있으므로 신뢰하는 사람에게만 전달해 주세요. 공유 중단·모임 종료 후에도 상대가 이미 저장하거나 캡처한 내용은 곰만나가 회수할 수 없습니다. 실제 서버 코드에 광고 목적의 정보 판매·제공 기능은 없습니다.

## 4. 보유 기간과 파기

보유·파기 정책: {{retention}}

현재 구현에서 인증 토큰의 기본 유효기간은 30일입니다. 이 기간은 인증 가능 기간이며 익명 사용자와 모든 서버 데이터가 30일 후 자동 삭제된다는 뜻은 아닙니다.

공유 OFF는 위치 전송과 조회를 중단하는 설정이며, 기존 서버 데이터를 즉시 삭제하는 동작과는 다릅니다. 이전 공유 회차의 정보는 다시 공유를 켜도 현재 정보로 제공하지 않습니다.

메모 삭제 시 메모와 사진 연결을 삭제하고, 사진 파일은 비공개 저장소의 정리 절차를 통해 처리합니다. 모임 탈퇴 시 해당 멤버 정보를, 모임 종료 시 모임의 멤버 정보를 삭제하며 관련 위치·메모는 DB의 연결 삭제 규칙에 따릅니다. 종료된 모임 기록과 익명 사용자 기록은 별도로 남을 수 있습니다.

서버 로그·백업·삭제 대기 사진의 실제 보유 및 파기 기간은 운영자가 확정해야 합니다. 현재 전체 익명 사용자 삭제 기능은 제공되지 않으며, 이 기능과 관련 데이터 파기 절차를 출시 전에 완성해야 합니다.

## 6. 선택 권한과 처리 중단

위치: 모임에서 공유를 켰을 때 사용합니다. 공유를 끄거나 iOS 설정에서 위치 권한을 변경할 수 있습니다. 공유를 켠 동안에는 모임 화면에서 나가거나 다른 앱을 사용하거나 화면을 잠가도 위치를 측정하고 전송합니다. 기기의 위치 사용 표시가 나타날 수 있습니다. 공유 OFF, 모임 탈퇴·종료, 위치 권한 해제 시 이 기기의 위치 측정과 전송을 중단합니다. 앱 강제 종료, 운영체제의 실행 제한, 네트워크 상태에 따라 공유가 중단되거나 지연될 수 있습니다.

카메라: QR 코드 스캔에 사용합니다. QR 스캔 영상을 서버로 업로드하는 기능은 없습니다. 카메라를 허용하지 않아도 코드를 입력해 참여할 수 있습니다.

사진: 시스템 사진 선택 화면에서 사용자가 고른 항목만 첨부합니다. 사진 보관함 전체 접근 권한을 요구하지 않습니다.

위치·카메라 권한을 허용하지 않아도 모임 생성·참여를 이용할 수 있으나 위치 공유·QR 스캔 등 해당 기능은 제한됩니다.
