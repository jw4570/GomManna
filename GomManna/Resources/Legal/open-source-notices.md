# 오픈소스 라이선스

현재 iOS 앱에는 Swift Package 등으로 별도 배포하는 제3자 라이브러리를 추가하지 않았습니다. 앱의 거리·중간 지점 계산에는 프로젝트 내부의 C 코드를 사용합니다.

지도, 사진 선택, QR 처리 등에는 iOS가 제공하는 시스템 프레임워크를 사용합니다. Apple 지도에는 해당 서비스의 저작권 표시와 이용 조건이 적용됩니다.

새 라이브러리를 앱에 포함하는 경우 해당 저작권 고지와 라이선스 전문을 이 화면과 배포물에 추가합니다. 서버에서만 사용하는 라이브러리의 고지는 서버 배포물에서 별도로 관리합니다.
